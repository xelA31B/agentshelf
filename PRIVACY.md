# Privacy Policy — AgentShelf

_Last updated: 12 November 2026_

This plugin is a set of instructions (skills) that runs inside Claude. It has no servers of its own.

- **No data collection.** The plugin author does not receive, store or process any data or reports.
- **What Claude reads.** During an audit Claude uses its own web search and page fetching to read public pages of the site you name (product pages, policies, robots.txt, llms.txt, feeds, API docs). Public business contact details may be read to check consistency. This happens inside your Claude session under Anthropic's terms and privacy policy.
- **Read-only.** The plugin never logs in, creates accounts, adds to cart, submits forms or pays.
- **No storage, no third parties, no tracking.**

Questions: https://github.com/xelA31B/agentshelf/issues
